<h2>Esse foi um projeto bacana que aprendi no <a href= "https//rodolfomori.com.br/devclub">DevClub</a></h2>
<h2>Dev Movies é um projeto desenvolvido para amantes do cinema e tecnologia. Ele apresenta uma plataforma interativa onde os usuários podem explorar informações sobre filmes, como sinopse, avaliações, elenco e mais. O foco é entregar uma interface elegante e funcional, promovendo uma experiência dinâmica e envolvente.
 </h2>
